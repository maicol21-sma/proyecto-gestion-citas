\# SISMEDIC — Frontend



Aplicación web para la gestión de citas médicas, desarrollada como proyecto formativo del programa Tecnólogo en Análisis y Desarrollo de Software (ADSO) del SENA.



\## Descripción



SISMEDIC permite organizar la gestión de información relacionada con pacientes, médicos, consultorios y citas médicas mediante una interfaz web.



El frontend se comunica con un backend desarrollado en Node.js y Express, que gestiona las solicitudes a la base de datos MySQL.



\## Tecnologías utilizadas



\- \*\*React:\*\* construcción de la interfaz de usuario.

\- \*\*Vite:\*\* entorno de desarrollo y compilación.

\- \*\*JavaScript:\*\* lógica de la aplicación.

\- \*\*HTML5:\*\* estructura de las vistas.

\- \*\*CSS3:\*\* estilos y presentación visual.

\- \*\*React Router:\*\* navegación entre páginas.

\- \*\*Git y GitHub:\*\* control de versiones y alojamiento del código.



\## Módulos principales



\- Inicio de sesión.

\- Pacientes.

\- Médicos.

\- Citas médicas.

\- Consultorios.

\- Centro de información.



El acceso a las páginas internas está protegido mediante rutas privadas.



\## Requisitos



\- Node.js y npm.

\- Backend de SISMEDIC configurado y en ejecución.

\- Base de datos MySQL configurada en el backend.



\## Instalación



1\. Clonar el repositorio:



&#x20;  ```bash

&#x20;  git clone https://github.com/maicol21-sma/proyecto-gestion-citas.git

&#x20;  ```



2\. Entrar en la carpeta:



&#x20;  ```bash

&#x20;  cd proyecto-gestion-citas

&#x20;  ```



3\. Instalar las dependencias:



&#x20;  ```bash

&#x20;  npm install

&#x20;  ```



4\. Iniciar el entorno de desarrollo:



&#x20;  ```bash

&#x20;  npm run dev

&#x20;  ```



5\. Abrir en el navegador la dirección local que indique Vite en la terminal.



\## Compilación para producción



Para comprobar y compilar el proyecto:



```bash

npm run build

```
